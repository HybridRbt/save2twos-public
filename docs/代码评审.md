# 代码评审与验证范围

## 当前实现

脚本使用 Twos 官方 v1 API、JSON 请求及 Bearer API key。凭据保存在 Drafts Credential，使用密码输入字段；取消授权、缺少 key 或正文为空白时停止。错误提示不输出完整响应或凭据，创建成功要求 HTTP 201，不自动重试创建。

正文、全量原生标签、原创建时刻和日期归档的合同见 [README](../README.md)；取舍见 [设计决策](设计决策.md)。历史版本包含已停用的旧接口和附注/回链试验，安装时使用当前分支的完整脚本。

## 历史修复

| 问题 | 处理与验证 |
| --- | --- |
| 取消凭据授权仍继续请求 | 检查授权 boolean 与必填字段；模拟取消时请求数为零 |
| HTTP 错误提示为空或暴露响应 | 使用固定提示及状态码；模拟失败时不记录凭据和完整响应 |
| 纯空白正文仍发送 | 使用 trim 校验，正常正文仍保留原格式 |
| 正文和原生标签重复追加来源 | 正文不追加 hashtag，仅通过原生 tags 表达来源 |
| 跨时区补发归档到错误日期 | 选择创建时区，按创建时刻的 IANA 规则计算日期 |
| 远端成功后状态失败导致误重发 | 显式提示已发送，不将整个 Action 标为失败 |

## 自动化证据

当前 69 项 Node.js 内置测试通过 VM 执行实际脚本，只替代 Drafts 专有对象及网络边界，无第三方测试依赖。测试凭据、UUID、正文、标签和状态为虚构值，不读取使用者账号。

覆盖新旧稿 30 分钟边界、未来时刻、跨日、毫秒、自定义时区、冬夏令时、原生标签合并与不修改原数组、授权取消、HTTP/网络失败、状态异常及旧状态兼容。旧稿偏好覆盖当地午夜、23/25 小时夏令时日、168 小时、到期与设备变化、偏好复用和取消失败。

运行方式见 README。自动化通过只证明模拟边界下的行为，不代表 Drafts/Twos 端到端或全部平台兼容。

## 实机证据与限制

基础发送、首次 API key 提示、简洁正文、原生标签、新旧稿时区选择、日期页面和真实创建时间已有既往实机反馈。基础功能的验收不扩展到后来增加的旧稿提醒暂停交互。

本次公开准备不更改主脚本和测试，也未使用真实 key 向 Twos 发送。发送成功/取消/失败时的状态规则、状态异常、新按钮、偏好持久化及相应真实客户端效果仍仅有模拟证据。新使用者需按 README 用自己的示例草稿核对首次发送。
